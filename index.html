用 WebGPU 在本机显卡上跑同一份 kernel：二进制逐对象比较，三进制位平面一次判 32 个。 数据量 1000 万对象——二进制 120 MB（超出 L2），三进制 3.75 MB（仍在 L2 内）。 这正是带宽差距开始兑现的地方，和 Rust 侧 32× 的前提一致。
WebGPU 需要 Chrome / Edge 113+ 且开启硬件加速。数据完全在本机 GPU 上，不上传。 想复现 Rust 侧的 10 倍差距：cargo run --release --bin trit_visibility（1000 万对象，超出 L2）。
