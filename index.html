十亿对象：二进制需要 3 × 4 GB = 12 GB 显存，本卡放不下；三进制只要 375 MB。 所以三进制真的跑十亿对象，二进制按显存预算取可容纳的规模跑同一份 kernel，按 G 对象/s 对比。 每轮背靠背提交、不等 vsync——运行期间 GPU 连续满载。
WebGPU 需要 Chrome / Edge 113+ 且开启硬件加速。数据完全在本机 GPU 上生成，不上传。 可长时间挂着跑；关闭页面后显存与 GPU 占用立即释放。轻量模式（1 亿对象） · 毒蘑菇分形页（3D 镜头） · 分形体素化 + 三进制 DDA · Rust 侧对照：cargo run --release --bin trit_visibility · 纯带宽基准：cargo run --release --bin gpu_bw
